# KidsGift.in

An e-commerce-style gift guide blog, built as a Jekyll site so GitHub Pages builds and publishes it automatically — no manual HTML editing needed to add a new post.

## How to add a new blog post (do this daily)

1. Create a new file inside `_posts/` named exactly like this:
   ```
   YYYY-MM-DD-a-short-title.md
   ```
   Example: `2026-09-06-best-gifts-for-newborns.md`

2. Paste this template at the top and fill it in:

   ```markdown
   ---
   title: "Your Post Title Here"
   category: "Toddlers"
   excerpt: "One or two sentences — this shows on the homepage and blog list."
   image: "/assets/img/your-cover-image.jpg"
   products:
     - name: "Product Name"
       price: "₹999"
       mrp: "₹1,499"
       rating: "4.5"
       badge: "Bestseller"
       image: "/assets/img/product-1.jpg"
       link: "https://amzn.to/your-real-affiliate-link"
     - name: "Second Product"
       price: "₹499"
       link: "https://amzn.to/another-link"
   ---

   Write your article here in plain Markdown. This becomes the body of the post,
   above the product cards.

   ## You can use headings

   And **bold**, lists, links — all normal Markdown.
   ```

3. `git add`, `git commit`, `git push`. GitHub rebuilds the site automatically (usually under a minute) — no other step needed.

**Notes on the template:**
- `image`, `mrp`, `rating`, and `badge` are all optional — leave them out and the layout adjusts automatically (a placeholder graphic shows if no image is set).
- The `products` list is what makes each post "shop-style" — each entry becomes a product card with a price and a **View on Amazon** button. Use as many or as few as you like; leave `products:` out entirely for a plain article post.
- Every post automatically shows the affiliate disclosure box near the top — you don't need to add it manually.

## Migrating your existing Blogger posts

You said you have 5–10 posts — at that count, manual is genuinely faster than scripting a converter:

1. Open each old post on Blogger, copy the text.
2. Create a new file in `_posts/` per the steps above, paste the text into the body, and add a `products:` block for anything you were linking to Amazon.
3. **Important for SEO:** Blogger URLs look like `kidsgift.in/2024/06/post-title.html`. This site's URLs will look like `kidsgift.in/post-title/`. If any of your old posts are already ranking in Google or have backlinks, set up a redirect from the old URL to the new one — otherwise you lose that ranking. The simplest way on GitHub Pages is an HTML meta-refresh redirect file at the old path; ask if you want this set up once you know your old URLs.

## Hosting on GitHub Pages with your custom domain

1. Push this whole folder to a GitHub repo (root of the repo, not a subfolder).
2. Repo → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, folder `/ (root)`. Save.
3. Under **Custom domain**, enter `kidsgift.in` and save (the `CNAME` file here already has it, this just confirms it).
4. At your domain registrar's DNS settings, add:
   ```
   A    @    185.199.108.153
   A    @    185.199.109.153
   A    @    185.199.110.153
   A    @    185.199.111.153
   CNAME    www    YOUR-GITHUB-USERNAME.github.io
   ```
5. Once GitHub shows the domain verified, tick **Enforce HTTPS**.

GitHub Pages builds Jekyll sites for you automatically — you do **not** need to run any build command or GitHub Action for this site to go live.

## Previewing locally before you push (optional but recommended)

If you have Ruby installed:
```bash
bundle install
bundle exec jekyll serve
```
Then open `http://localhost:4000`. This lets you check a post looks right before it's public.

## Before you publish for real

- [ ] Replace every `https://amzn.to/REPLACE-ME-...` placeholder link in `_posts/` with your real Amazon Associate links.
- [ ] Replace `hello@kidsgift.in` in `contact.md` with your real email.
- [ ] Add real product photos to `assets/img/` and reference them in each post's `image:` fields — real photos convert far better than the placeholder icon.
- [ ] Double check `affiliate-disclosure.md` names every affiliate program you're actually enrolled in.
- [ ] Submit `https://kidsgift.in/sitemap.xml` (auto-generated by the `jekyll-sitemap` plugin — no action needed to create it) to Google Search Console once the domain is live.
- [ ] If you want visible ads (e.g. AdSense) or analytics, those are just script tags — add them inside `_layouts/default.html`'s `<head>`, and update `privacy-policy.md` to mention them.
